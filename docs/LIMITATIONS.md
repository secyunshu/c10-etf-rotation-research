# 局限、反例与距离交易的差距

研究结论：C10在所用条件性历史中表现较好，值得继续验证；现有证据不能证明稳定未来超额收益。下列局限会直接改变对高收益数字的解读。

## 选池和研究过程

- 36只名单用2026年查询的AUM和当前基金身份筛选，再回看2022—2025。没有完整当时可见名单与退市链，存在幸存／选池日期偏差。
- 2022—2025已在旧研究中出现。C10这一轮先在2022—2024选唯一候选，再看连续2025，只能算本轮流程隔离，不能恢复全新样本外独立性。
- 先前研究有数百个身份和多轮探索。本轮36模板统计修正不覆盖所有历史搜索、选池与人工决策。回测越多，偶然高收益的可能性越要认真对待。
- 没有把2026历史收益用于本包选参、收益展示或追加验证。未来观察的证据必须另行积累。

## 统计不确定

原36模板开发检验，5／20／60日块重采样的5bp家族p值为0.1139／0.0969／0.0716，均未达到0.05。本范围也不是全部历史试错的全局校正。

C10相对C00，在完整2022—2025的年化算术日收益均值差95%条件区间分别为[−0.43, 26.93]、[−0.67, 28.12]、[−0.29, 27.81]个百分点，均跨零。这些不是CAGR差区间，也不是未来收益预测。

机构化同事前风险诊断中，C10相对全部合格趋势等权的结果较强，相对四类资格静态的区间仍跨零。共同预测风险不等于实际风险一致，诊断对照也不自动成为可单独部署的新基准。

## 集中和尾部

原C10初始目标85.5%单只ETF，实际最高约88.97%。2025贡献59.29%的累计美元利润，金银贡献全期43.08%。这既受行情影响，也受先前资金复利增长影响；美元利润占比不能直接衡量每年策略能力。

22.55%是这个样本中观察到的收盘回撤，不是风险上限。原假设冲击试验中，集中标的隔夜下跌35%可造成账户约30%—31%的损失，而且该试验仍假设能以正价格成交；没有估计这种事件的概率。停牌、流动性枯竭或跳空时损失可能更大。

## 执行和数据风险

- 默认日线Backtrader没有开盘成交量／盘口队列模型，原假设整笔即时成交。零量、Partial和跨日订单不应被这些历史收益当作已通过。
- 5bp／20bp是成本情景，不是观测到的真实价差、冲击或订单成交保证。历史最大订单／ADV20比例较小，也不能证明开盘集合竞价容量。
- 费用是固定研究费表；个人税负、股息预扣、真实结算限制、券商购买力、现金利息都可能改变结果。
- 本研究只验证单一冻结数据版本的计算。来源会有遗漏或修订，当前池偏差仍在。
- 新paper execution v2曾做本地订单生命周期测试，但“卖确认后下一session买”的政策不同，不能把本包收益转授v2。合成执行测试不是实盘验证。

## 从这里到模拟／实盘

本包适合阅读、复核和离线研究，未接券商账户。下一阶段应冻结规则，收集真实未来信号、可成交报价与成交报告，核实费用／结算／购买力，事先约定资金、集中度和亏损红线，再评估是否进入更真实的模拟或小规模实盘。

原计划的20／63／126交易日只用于描述性检查，252日评估、最多延长至504日；不得根据短期收益随意选赢家、换阈值或把多个同期账户当独立样本。这个发布包不自动运行该观察流程，也不声称上述未来观察已经完成。
