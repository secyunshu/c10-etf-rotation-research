# 当前标准 V2.3

2026-11-13 采用。`standard/CURRENT.json` 绑定 [V2.3 策略](../standard/v2_3/STRATEGY.json)，离线复现入口是 `PYTHONPATH=src:. python -m scripts.current_standard`。

年度候选池沿用 95 个候选、36 个类别和 21 个经济风险组。用截至上一年底可得的规模归档，选每个类别规模最大的代表，门槛为 50 亿美元。次年首个交易日启用新池。换池前保留原持仓和应收股息，交易时按新目标处理。缺少当年已核验名单时须先补充并验收来源。

每月最后一个交易日，用至少 253 条收盘观察计算 252 个交易日总回报。资格条件是未复权收盘至少 5 美元、20 日均成交额至少 1000 万美元且每天有成交。按总回报降序，分数相同按代码排序，同一风险组最多一只。前两只各占 45%。如果其中有 QQQ 或 SPY，10% 底仓配 SHY，否则配 QQQ。SHY 的动量不参与资格筛选。合格标的不足两只时停止生成目标，先检查池与数据。

月末收盘生成信号，下一交易日开盘执行。名单相同也按目标再平衡，成交计入整股限制、费用和现金约束。标准用于研究和手动模拟，实际价格以交易时可见报价为准。

两个离线账户窗口各自从 50,000 美元开始。2022–2025 连续持有至 2025 年末收盘。2026 年在首个交易日新开仓，估值至美东 11 月 11 日收盘。标准的参考账户使用原费用与单边 5 bp。两段各含轮动、SPY 和 QQQ。收益口径、逐年结果及数据限制分别见[四年报告](../experiments/annual-qqq-spy-sleeve/REPORT.md)和[2026 报告](../experiments/conditional-sleeve-2026/REPORT.md)。

旧 V2.2 有 SHY 动量门槛和 95% 目标投入，历史账户可在 [v2.2.0 标签](https://github.com/secyunshu/c10-etf-rotation-research/tree/v2.2.0)下按其原命令复现。
