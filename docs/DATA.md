# 数据、来源与可核验范围

> 本页描述V1历史冻结版。当前标准为[V2历史池与分组规则](STANDARD_V2.md)，复现请看[V2指南](REPRODUCE_V2.md)。

## 包含哪些数据

`data/market/`包含原36只候选ETF、SHY以及基准SPY，共38资产，每只1,256行日线，日期2020-12-31至2025-12-31。2021年用于预热，回测账户从2022-01-03开始。966条现金分配记录、6条拆股记录另列。所有重跑输入已经包含，无须调用供应商接口。

| 文件／字段 | 含义 |
|---|---|
| `{symbol}.csv.gz` | 未复权open/high/low/close、volume、turnover、TR及成交额检查字段 |
| 第一列日期 | XNYS交易日，无时区的交易日期；不是UTC午夜成交时间 |
| `volume` | 当日成交股数 |
| `turnover` | 供应商实际当日美元成交额；不以close×volume代替 |
| `tr` | 起值100的含分红、拆股总回报信号序列；不拿它作成交价 |
| `turnover_lower/upper` | SPY文件附加的成交额检查上下界，与真实turnover相同；其余37文件无此附加列 |
| `turnover_proxy` | SPY文件附加来源标志，本包为0；其余37文件直接保留真实turnover |
| `CASH.json` | 按symbol分组：ex_date、真实pay_date、每股amount、source |
| `SPLITS.json` | 按symbol分组：生效day、每旧股得到的新股数、source |
| `MANIFEST.json` | 固定身份、成员、起止日期、分类与文件SHA256 |
| `POTENTIAL_AMBIGUITIES.json` | 既有资格歧义检查记录 |

数据身份为`MODERN38_C10_BENCHMARK_20201231`。其38文件是数据容器；C10／C11／C00只使用37 feeds，SPY不参与排名。相同基金的输入来源保持一致。

价格和除息日期截止2025年末，但已发生除息对应的真实支付日可以在2026年。末期未支付分红以锁定应收入资产，不提前变成购买力；保留这一支付元数据并非使用2026价格或事后策略收益。

## 来源优先级

主要价格和公司行动来自Futu OpenAPI日线／复权事件／派息明细，历史期固定截止2025-12-31。比较来源主要用于发现或核对冲突；有冲突时优先使用经核验的富途字段，不以免费源直接覆盖。派息明细与复权字段也可能内部不一致，因此采用明确的、留痕的规范化决定。

- [Futu历史K线接口说明](https://openapi.futunn.com/futu-api-doc/quote/request-history-kline.html)：K_DAY、未复权、正常交易时段，用真实OHLC和量额。
- [Futu复权信息接口说明](https://openapi.futunn.com/futu-api-doc/quote/get-rehab.html)：现金与拆合股事件信息。
- [Nasdaq ETF资料](https://www.nasdaq.com/market-activity/etf)：2026-11-07查询的AUM及基金身份用于固定名单。查询日不等于每只基金的经济报告日。
- [Yahoo Finance](https://finance.yahoo.com/)和发行人派息资料：独立支持特定金额／除息日期。Yahoo除息日不能替代真实支付日。

原研究更早曾比较其他免费源，但本包的现代规范行情主要采用富途经核验源。来源记录不表示各供应商独立无误，也不代表它们保证本研究结论。

## 公司行动与修正

总回报序列遵循原冻结递推：

`TR[t] = TR[t−1] × (raw_close[t] + 当日每股现金分配) × 当日拆股比例 / raw_close[t−1]`

没有事件时，现金为0、拆股比例为1。现金金额以历史股数单位表达。信号TR与实际账户分红处理是两回事：账户按照实际持仓计算应收，直到真实支付日之后才允许花这笔钱。

[修正记录](../evidence/DATA_CORRECTIONS.json)保留BND、VGSH、VCIT、USHY的9次金额与2次除息日期修正。金额根据富途派息分项求和、Yahoo作佐证；BND和VGSH的2023年7月除息采用富途复权事件与Yahoo均支持的7月3日，并保留真实支付日。记录中早于本包起点的2020年事件只解释历史处理，不注入本包数据。

旧项目还曾修正DIA／QUAL／VEA／VWO事件与XLC预热。本包不包含DIA、QUAL、VWO，VEA的该次事件早于本包起点；不能把这些旧修正全说成本次38资产回测受影响事项。XLC已有足够真实2021年预热，不生成上市前价格。

原始数据、旧冲突和规范版本在原研究分开保留。本仓库提供运行所需的完整规范版本与修正说明，不批量发布供应商网页缓存或2026行情。

## 能核验到哪一层

1. **数据完整性**：公开manifest验证所用文件没有意外变更。TR递推、OHLC、日历、事件和截止边界另有加载检查。
2. **信号和成交可复现性**：从公开数据生成排名／目标，并在原生Backtrader中重新产生订单、持仓、现金与净值，对比已保存参考。
3. **指标可复算性**：独立从每日账户复算年度／累计收益、回撤、Sharpe和其他指标。
4. **外部真实性**：仍需读者按来源另行抽查。哈希证明输入版本一致，不能证明供应商每个观察都正确；原供应商完整响应不在本包中。[上游哈希索引](../evidence/UPSTREAM_HASHES.json)说明其存在与来源链，不能用它代替数据本体或独立核验。

本包未提供完整历史上市／退市／AUM可见时点数据库，因此第1—3层通过不消除当前名单与幸存偏差。后来重新下载的历史可能修订，不应静默覆盖这里的冻结输入。任何新版本须保留旧结果并单独命名。
