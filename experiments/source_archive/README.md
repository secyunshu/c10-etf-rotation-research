# 原始研究源码与测试归档

这里保存历史池分组、真实月末13612W、六个前2只动量变种的原始研究脚本和测试。9个脚本与8个测试模块逐字节复制，SHA及测试函数列表在[INDEX.json](INDEX.json)。计划、协议和审查元数据将本机绝对路径替换为来源标识，记录原始与公开版本两份SHA，不称元数据原文逐字节相同。

原始集成测试依赖研究机上的供应商证据目录和历史审计链，因此本目录**不由公开仓默认pytest收集，也不宣称这些归档测试在干净克隆中直接可运行**。公开可执行版本使用`c10standard`和`c10experiments`，对应活跃测试在仓库`tests/`，其实际运行结果、覆盖对应关系与限制单独记录。

`group_cap`保存旧池／新池四格研究实现；`calendar13612w`保存固定权重实验；`top2_variants`保存六机制和局部统计研究。过去研究中的默认K1等措辞按当时版本保留，不覆盖当前用户指定C11默认。
