# ETF轮动标准方案V2

2026-11-10按用户明确选择，标准采用以下两项更新：使用2022年起点前已公开的历史规模资料重建候选池；经济风险组内最多选择一只ETF。2026-11-11用户明确将默认改为C11前2只，C10前1只及C00前3只保留为对照。这是已见历史之后的规则选择，不是新的样本外验证。标准文件为[STRATEGY.json](../standard/STRATEGY.json)。

## 基金池与资料时点

使用2022-01-03开始前的2021年归档reported AUM，门槛50亿美元，在原95候选和预定类别内选规模最大代表。36类别中26保留、9替换、1固定候选未达门槛；35类别赢家中的SHY只保留为防守资产，得到34风险候选＋SHY。SPY、QQQ都在风险池中。完整[逐类比较](../standard/evidence/historical_pool_comparison.csv)与[95候选观察](../standard/evidence/historical_candidates.csv)包含原始规模字符串、归档URL、捕获日和hash。

原2026名单用于2022回测存在选池时点前视风险。V2修正了这部分信息使用，但候选/类别仍继承2026研究设计，归档规模日期不同且AUM专属经济日期未完全确认，历史退市覆盖不全。因此仍是**条件性历史重建，不能称完全无前视、无幸存偏差的PIT全市场池**。AUM是基金资产规模，20日成交额是交易流动性，二者各有用途。

本标准采用固定池；年度重新选池未纳入此次更新。没有新增MTUM或按回测收益补基金。

## 信号与选择顺序

1. 每次月末XNYS最后交易日收盘，用已知数据评估；下一交易日开盘执行。首次决策为2021-12-31收盘，2022-01-03开盘。2026重置账户首次决策为2025-12-31。
2. 候选至少253条真实观测、未复权收盘≥5美元、过去20交易日实际美元成交额均值≥1000万美元且20天均有正成交量。流动性是资格过滤，不按成交额排序。
3. 按含分红/拆股的252交易日总回报降序，代码升序破同分。依次挑选未占用风险组的ETF，直到K个固定槽；同组其余候选跳过。
4. 已选槽的动量必须严格超过SHY同252日动量。失败或缺失槽的资金转SHY，不递补后续ETF、不把其余风险仓放大。
5. 预部署风险预算90%÷K，余量SHY，全体乘95%一次。K1/2/3每风险槽目标分别85.5%/42.75%/28.5%，全部通过时SHY9.5%、现金约5%。整股、费用与行情使实际权重漂移。

K1只持一个风险候选，分组限制数学上不改变选择；分组效果主要体现在K2/K3。策略无新止损、波动目标、杠杆或做空。

## 成交、分红和拆股

使用已验证Backtrader原生Cerebro/BackBroker、订单、Position、费用、TimeReturn。新代码仅做便携读取、信号、必要公司行动适配和独立财务核验。未复权OHLC用于成交，信号用此前收盘，95%部署只乘一次。原生同日开盘卖先买后、全量成交、整股，未建盘口或容量模型，真实购买力/结算及开盘冲击未实证。

分红除息时计入锁定应收，实际支付日结束后的下一交易日才可投入；拆股同步原生Position与Trade单位，不生成收益。QUAL和BIL本轮特定冲突经发行商核对、用户批准，见[补充裁决](../standard/evidence/DATA_CORRECTIONS.json)。其它原批准事件也保留来源。

固定费用、税0和单边5/20bp滑点沿[旧费用说明](STRATEGY.md#费用)，并在标准JSON中完整列出。ETF管理费已体现在净值/价格，不重复扣；闲置现金不生息。

## 三种账户口径

|cohort|起点与终点|展示指标|
|---|---|---|
|historical2022_2025|2022-01-03新50k，2025-12-31最后开盘清仓|2022–2025年度及全期|
|reset2026|2026-01-02新50k，2026-11-06收盘估值，无强平|2026累计YTD|
|continuous2022_2026|从2022原生连续运行，2025末不清仓，至2026-11-06收盘|2026以自身2025-12-31收盘NAV为分母|

年度收益用上年末NAV或账户初始50k作分母，回撤含期初资本；完整回撤跨年保留最高点，不能用年度最大回撤代替。2026不外推年化；它已被研究过，所有新规则比较仍是探索性，不是新独立OOS。

SPY/QQQ为初始95%投入、余现金、分红留现金的同费买持；60/40是SPY/IEF每月再平衡，账户目标57%/38%加5%现金。基准与轮动不是相同风险敞口。

## 标准采用与证据边界

采用标准是规则治理决定，不是策略收益或实盘资格通过。当前默认C11的2022–2025年化22.11%、回撤21.36%，2026新账户+9.39%、回撤25.25%。旧默认C10对应31.24%／22.55%，2026为−4.43%／37.95%，该负证据保留；C00亦完整报告，不选择最佳年份或起点口径。分组降低已观察2026部分回撤，但两池历史收益均有代价，历史池K3全期回撤还恶化。

旧V1数据与复现保留，新标准未自动接管旧模拟/前瞻链，没有下单接口或实盘授权。[V2结果](../standard/results/RESULTS.md) · [复现](REPRODUCE_V2.md) · [旧版对照](V1_OVERVIEW.md)

固定族标识`C10_HISTORICAL_GROUP_CAP_V2`是保留的历史兼容ID，不表示当前只持一只；实际默认由`default_rule=C11`确定。每个通过门槛的风险槽目标42.75%，未通过的槽转SHY。
